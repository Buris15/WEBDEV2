# Book Library CRUD Application

## Project Description

The Book Library CRUD Application is a simple web-based system for managing a collection of books. It allows users to add new books, view all available books, edit existing book information, and delete books from the collection. The application uses Spring Boot, Thymeleaf, Bean Validation, and a layered Controller-Service-Repository architecture.

## Functional Requirements

* REQ-1: The system shall allow users to create a new book by entering its title, author, and publication year.
* REQ-2: The system shall display all books currently stored in the library.
* REQ-3: The system shall allow users to edit the title, author, and publication year of an existing book.
* REQ-4: The system shall allow users to delete an existing book from the library.
* REQ-5: The system shall validate required book information and display appropriate error messages when invalid data is submitted.
