# WEBDEV2 F1 evidence checklist

Capture actual evidence from your computer and save it here:

1. `01_application_startup.png` — Maven/Spring Boot running against MySQL.
2. `02_pet_list.png` — browser list showing records loaded from the API.
3. `03_pet_list_network.png` — DevTools request URL, HTTP 200, and JSON page with `content`.
4. `04_pet_detail.png` — selected pet detail with owner, appointments, and vaccinations.
5. `05_pet_detail_network.png` — detail GET request/response.
6. `06_sql_comparison.png` — SQL query output matching the selected browser pet.
7. `07_empty_state.png` — actual empty list state.
8. `08_not_found.png` — actual 404 for a nonexistent ID.
9. `devtools_diagnosis.md` — one real symptom, cause, fix, and verification.

Screenshots must be actual captures. Do not submit mock output or expected results as evidence.
